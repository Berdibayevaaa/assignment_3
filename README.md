Here I practiced using CSS media queries and the Bootstrap grid system to make pages responsive for mobile, tablet, and desktop screens.

Task 0: Responsive Typography
Changed font sizes of headings and paragraphs using media queries. Small font for mobile, medium for tablet, and large for desktop.

Task 1: Responsive Layout with Media Queries
Created three boxes with plain CSS and flexbox. They show up in one row on desktop (3 boxes), wrap on tablet (2 boxes on the first row and 1 on the second), and stack vertically on mobile (1 box per row).
<img width="912" height="433" alt="image" src="https://github.com/user-attachments/assets/9edf962d-e076-47c8-8ef4-2a18b1899cd7" />

Task 2: Bootstrap Grid System
Made the same three boxes using Bootstrap 12-column grid classes (col-12, col-md-6, col-lg-4) without writing extra CSS for columns.

Task 3: Bootstrap Navigation Bar
Created a simple navbar with a logo on the left and menu links on the right. It automatically turns into a hamburger menu on smaller screens.

Task 4: Combined Portfolio Project
Combined all the tasks into one page:
- Navbar at the top with a logo image and hover effect on links.
- Responsive title and text from Task 0.
- Main area split into two parts: left side has 3 responsive boxes, and right side has a sidebar with my info and contacts.
- Footer at the bottom of the page.
